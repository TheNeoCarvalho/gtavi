# 01 — Pesquisa Consolidada

> Fontes: Unbounce Conversion Benchmark (Q4 2024, 464M visitas), Hotmart Blog 2026, Backlinko 2026, CXL, NN/g, Landy AI, SERP Blocks 2026, Studio Meyer 2026, Line25 2026, planetonemedia, growthsuite.net, homepageauditor.com, tagembed, idealmarketing, monitoração da LP concorrente monetizecomgta6.com.br.

## 1. Números que guiam decisões (CRO)

- Taxa mediana de conversão de landing pages: **6,6%**; top 25% > 10%; top 10% > 11,45% (Unbounce).
- Conversão por fonte: e-mail 19,3% | busca paga 3,2% | orgânico 2,7% | **social frio 1,5%** | direto 3,3% (Backlinko).
  - → Público vindo de redes sociais é FRIO. A página precisa educar + CTA. Tráfego social = principal origem de um pack como este.
- CTA vermelho converte ~21% mais que verde; laranja ~15%+; azul ~10% menos (Unbounce/VWO/Performable). **O que mais importa é CONTRASTE com o entorno + efeito Von Restorff (cor única na página)**.
- Red aumenta urgência em contexto de escassez (Univ. Virginia 2013): fundo vermelho + escassez = mais disposição a pagar.
- 60-30-10 rule: 60% fundo, 30% secundária, 10% accent (CTA). Máximo ~3 cores + neutros.
- ~82% usuários usam dark mode; dark-first = padrão premium em gaming/tech/luxo; OLED economiza até 60% energia; dark bem feito aumenta tempo no site ~18%.

## 2. Estrutura validada de LP de infoproduto (7 elementos Hotmart + benchmarks)

1. **CTA visível acima da dobra** (header + hero).
2. **Headline que resolve um problema** — não genérica.
3. **Prova social** (números, depoimentos, avatares).
4. **Lista de benefícios em bullets** (value stack).
5. **"O que você recebe"** — listar conteúdo do produto reduz incerteza/objeção.
6. **Garantia + formas de pagamento/parcelamento visíveis** (quebra objeção de risco).
7. **FAQ** (responde objeções finais).
- Erros que derrubam conversão: formulários longos, múltiplos CTAs, lentidão, design confuso, **falta de prova social**.
- Uma LP tem UM objetivo único. Todo elemento serve ao CTA de compra.

## 3. Tendências UI 2026 aplicáveis

- **Dark-first** com paleta calibrada (nunca preto puro `#000`; usar cinzas escuros + acentos que "brilham").
- **Glassmorphism 2.0** — uso cirúrgico (navbar, cards sobre gradientes); `backdrop-filter` custa caro → limitar.
- **Gradient mesh / Aurora UI** — gradientes multi-ponto orgânicos no fundo (2-3 blobs animados máx.; `will-change` limitado; testar em Android barato).
- **Bento grid** — comunica muitos benefícios rápido; colapsa em coluna única no mobile.
- **Micro-interactions como sistema** — tokens de timing/easing globais; feedback funcional (hover glow, focus, sucesso).
- **Kinetic/variable typography** — display forte com peso/width variável.
- **Neon/cyberpunk** — gamer/luxo/tech. Neon pink + azul elétrico + roxo sobre quase-preto.
- **3D/WebGL** — usar com parcimônia (diorama/hero mockup); progressive enhancement.

## 4. Psicologia das cores (decisão de paleta)

- **Roxo**: luxo, criatividade, premium, "entre a confiança do azul e a energia do vermelho" — ideal para produto gamer premium.
- **Azul**: confiança, segurança — usado em elementos de segurança/pagamento.
- **Rosa/Neon**: energia, entretenimento, juventude — afina com público criador de conteúdo.
- **Vermelho**: urgência/escassez — reservado para CTA e badges de limite.
- **Escuro**: exclusividade, sofisticação, potência.
- CTA único, cor única na página, contraste ≥ 4.5:1 para texto, ≥ 3:1 para UI.

## 5. Contexto do produto / mercado GTA VI + Shorts

- GTA VI = maior lançamento da década; cada trailer/vazamento gera busca em massa.
- YouTube Shorts: monetização com 1.000 inscritos + 10M views em 90 dias OU 4.000h; **60% dos criadores já monetizam**; fundo de US$100M→ receita de anúncios (2023+).
- YouTube 2026: punição a conteúdo repetitivo e reciclado → **originalidade/valor único importam** (vantagem competitiva para pack com vídeos tratados, narração, formato vertical).
- UGC/monetização in-game do GTA 6 (2026) amplia hype → mais busca por conteúdo.
- Concorrente (monetizecomgta6.com.br): estrutura = hero com número de vídeos + bônus, "onde postar", "oportunidade da década", "o que recebe" (9 cards), plano 3 passos, "como funciona", acesso/plataforma, bônus + bônus PRO, depoimentos carrossel, comunidade WhatsApp, pricing 2 planos com escassez, garantia, FAQ, CTA final, footer + popup oferta.
  - Usamos apenas como referência de estrutura/funil. Identidade visual e copy serão originais (marca própria **VIZION**).

## 6. Decisões de projeto (tradução da pesquisa em escolhas)

| Decisão | Justificativa |
|---|---|
| Dark-first + aurora/gradient mesh | Público gamer + premium; tendência 2026 dominante; cores neon "pop" no escuro |
| Paleta roxo/rosa/azul + accent laranja CTA | Roxo=premium, rosa=entretenimento, azul=confiança, laranja/vermelho=urgência no CTA (Von Restorff) |
| Hero com mockup de player vertical + stat stack | Above-the-fold: CTA + prova + claridade do produto |
| Bento grid nos benefícios | Densidade de informação sem parecer lista genérica |
| Countdown + contador de vagas + últimos acessos | Urgência/escassez (mais forte para tráfego frio social) |
| Garantia 7 dias + pagamento seguro + "compra única" | Quebra objeção de risco |
| FAQ com 8-10 perguntas reais | Fecha objeções no fim do funil |
| SEO técnico completo | Page Experience é ranking factor; OG/Twitter Cards para compartilhamento social |
| Mobile-first | ~65% do tráfego é mobile; social = mobile |
